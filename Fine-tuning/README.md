# Linguistic Confidence Study

## Overview

This repo contains a reference implementation for revisiting linguistic confidence as a practical and scalable approach to LLM uncertainty estimation.

Specifically, we provide four components:
* [The dataset of hedging expressions with human-annotated confidence scores.](#Evaluation-Benchmark)
* [A confidence mapper to quantitatively evaluate the performance of linguistic confidence.](#Lightweight-Mapper)
* [The first systematic study of LC across modern LLMs and QA benchmarks](#Comprehensive-Study)
* [A fine-tuning framework that improves LC reliability.](#Improvement-Strategies)



## Installation

```bash
uv sync
```

## Evaluation Benchmark

We construct a large, human-annotated dataset of linguistic uncertainty expressions, capturing diverse hedging expressions beyond fixed phrase lists. This dataset enables systematic evaluation of how well confidence mapping aligns with human judgments.

## Lightweight Mapper
We train an efficient model that maps uncertainty expressions into confidence scores at near-zero cost. Unlike LLM API–based methods, which are expensive and slow, our mapper incurs negligible latency, making it suitable for applications with strict real-time requirements. Experiments on the evaluation benchmark demonstrate reliable mapping performance. 

`benchmark_mapper.py`

The file provide all process for training a confidence mapper. run:

```bash
python benchmark_mappers/benchmark_mapper.py \
    --confidence_regressor=linguistic \
    --llm_name=gpt-5-mini \
    --model_weights_path=mapper_weights/human_anno_trained_reg_head.pth \
    --benchmark_set_path=benchmark_mappers/datasets/linguistic_confidence_benchmark.csv
```

## Comprehensive Study
We conduct a large-scale evaluation of linguistic confidence across multiple state-of-the-art LLMs on benchmarks of varying difficulty, including SimpleQA, PopQA, and NQ-Open. Our analysis covers both calibration and discriminability, revealing that most SOTA LLMs, such as GPT-5, perform poorly at linguistic confidence. With carefully designed prompts, however, LC can achieve comparable performance to other methods while remaining cheaper, more interpretable, and more aligned with how general users interact with language models. 

To run this model:
```bash
python -m llm_linguistic_confidence_study \
    qa_model=<your_qa_model_path> \
    confidence_extractor=<select_one_confindece_method> \
    dataset=<select_one_dataset> \
    pre_runned_batch=<your_pre_runned_batch_filename> \
    metrics=<select_one_metrics>
```
Or, you can find more detailed instructions in `llm_linguistic_confidence_study/eval_scripts.sh`.

## Improvement Strategies
We design a fine-tuning framework that enhances linguistic confidence through supervised learning. Concretely, we fine-tune a Qwen-8B model on our constructed dataset and evaluate it across multiple QA benchmarks. The results show that this framework consistently improves calibration and discriminability, highlighting supervised fine-tuning as a promising direction for advancing linguistic confidence.

`improve_llm_linguistic_confidence/__main__.py`

This file contains all process of finetune the uncertainty model, run:
```bash
python -m improve_llm_linguistic_confidence \
    config_name=mapper0
```
